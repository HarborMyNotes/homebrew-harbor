# HarborMyNotes Harbor

## How do I install these formulae?

`brew install harbormynotes/harbor/<formula>`

Or `brew tap harbormynotes/harbor` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "harbormynotes/harbor"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
